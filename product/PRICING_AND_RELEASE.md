# 商品化与 Agensi 上架路线 v0.2 / 2026-10-20
来源：2026-10-04 Agensi 邀约，2026-10-05 Joeri 回函；https://www.agensi.io/terms （查阅 2026-10-20，页面最后更新 2026-10-18），https://www.agensi.io/sell。

## 已核商业条件
免费上架、非独家、自主定价；创作者分成税前/税后口径必须按平台“净售价（不含 VAT/销售税）×70%”计算。30%平台费含支付处理；退款冲减分成；不等于可预测销量。
平台 2026-10-18 条款：最低付费价 $1，低于 $5 只能用积分，直接卡支付 $5 起；出售需 Stripe Connect 或 Zoneless USDC(Solana) 正式入驻及身份核验；paid listing 不得引流外部付费购买；每个 skill zip 必须有有效 SKILL.md，8项安全扫描+人工审核；平台承担买家VAT/销售税代收汇缴，不代表卖家免缴自己的收入税。
2026-10-04 邮件平台自称 65,000+ 月访，未审计。平台拒绝从标准70/30改成80/20。不要把邀约等同需求验证。

## 开源和付费必须区分
当前 main MIT 开源、全部22名人研究案例已公开。不能追溯撤回别人已有MIT权利，不能将完全相同的文件假装独家卖。Core 开源研究版（仍用MIT）；Premium 有实质新增原创资产、地区实用内容、可运行清单、评分量表及专业维护。付费包另建私有发布目录和许可，未做权属审核和单元测试前不得直接公开 Premium 全量；无需恶意反爬或混淆。
本 PR 只添加公开研发草案与测试协议，不等于已制作付费产品，也不是上市批准。

## 定价假设（需 A/B 真实测试）
- Free：基础女性案例与通用决策框架。
- $7–9：一题一解 / Career + money / relationship 跨阶段入门独立场景包（一次性）。
- $15–24：China 或 US/UK 专题地区决策工具包（一次性），仅当本地资料+案例+具体模板验证完。
- $19/月起：定期更新型会员，仅当有确实可兑现的持续更新机制、真实可验证的成本/售后能力时考虑；现金压力不能成为仓促承诺订阅的理由。
试销首版优先 ONE single-purpose paid skill + free core，不同时开发数十个SKU。以平台内实际购买、退款和复用为依据调整。

## 现金流模型（示例，无销量保证）
净收入/笔 ≈ 0.70 × 不含VAT的成交价，另需扣除退款、所得税、团队制作与客服成本。
$9 × 100单 → 名义创作者收入 $630；$19 × 100单 → $1330；仅是假设，不代表已完成销售。

## 关键验收
1. 用户安装后用普通话/英语首次提问能得到可执行决策卡；无二次付费门槛。
2. ZIP 仅含必要原始文件、无凭据/API、无个人隐私、无自动外呼/可疑脚本；安全扫描通过。
3. 标题、截图、listing 未许诺“正确率100%”“替代医生/律师/理财顾问”。
4. 原始 GitHub 开源授权、Premium 的版权及资料引用合法性由专人核对。
5. 完整运行 Agensi 沙盒或真实创作者后台的安装流程，并核对浏览器、官方条款和当日提现路径；未本人完成认证与账户连接，不得假报已上市。
6. 未收到真实订单和结算凭证，不把访问量当回款。
